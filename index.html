ส่งอาการทาง LINE

ฝั่งคุณทำแค่นี้ ที่เหลือช่างจัดการ

  1. คุณส่งรูปถ่ายรูปหรืออัดคลิปส่ง LINE ใช้เวลาไม่ถึง 2 นาที
  2. นำรถเข้าร้านไม่ต้องจองคิว ทักบอกก่อนจะรอน้อยลง
  3. อ่านใบราคาใน LINEแยกทุกรายการ อ่านจากที่ไหนก็ได้
  4. คุณตอบ “ทำ”เลือกทำบางรายการได้ งานทั่วไปเสร็จในวันเดียว
  5. รับรถจ่ายตามใบราคา พร้อมดูอะไหล่เก่า

ถามกันบ่อย

ไม่เจอคำถามของคุณ? ทักมาถามช่างทาง LINE ได้เลย

ส่งรูปให้ช่างดู หรือเข้าไปตรวจแล้วไม่ซ่อม ต้องเสียเงินไหม

ไม่เสีย ตรวจรถฟรี ส่งรูปให้ช่างดูก็ฟรี ถ้าตรวจแล้วยังไม่ซ่อมก็ไม่มีค่าใช้จ่าย

ต้องจองคิวก่อนไหม

ไม่ต้อง แต่ทักทาง LINE ก่อนจะรอน้อยลง ช่างจะเตรียมอะไหล่ไว้ให้

ซ่อมกี่วันเสร็จ

งานทั่วไปเสร็จในวันเดียว ถ้าต้องรออะไหล่ เราบอกวันรับรถตั้งแต่ตอนแจ้งราคา

ใช้อะไหล่แท้หรือเทียบ

เราเสนอให้ใช้อะไหล่แท้ คุณภาพเป็นหลัก เพื่อให้อายุการใช้งาน และประสิทธิภาพดีที่สุด ทั้งนี้ขึ้นอยู่กับงบของลูกค้าด้วยครับ
